# Your Helping Hands

A portable, responsive three-page website for a small Toronto home-cleaning company. Built with HTML, CSS, and JavaScript; no paid services, dependencies, or backend required.

## Edit and preview

Install Node.js, then run `npm run build`, `npm run check`, and `npm start`. Open http://127.0.0.1:4173. Page copy and prices live in `build.mjs`, styles in `styles.css`, and email request behaviour in `script.js`. Rebuild after edits. The original supplied logo is `assets/logo.jpg`.

## GitHub Pages

Push to a public GitHub repository. In Settings → Pages, choose GitHub Actions as the source. The included workflow builds and deploys `dist/` on pushes to main or master. Relative links support a repository subpath. Documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Move to another host

Upload the contents of `dist/` to any static web host. No server runtime or database is needed. A custom domain can be attached later without rebuilding the design.
